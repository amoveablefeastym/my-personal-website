*Personal project · single-file web app · open source*

Learning Russian vocabulary isn't just memorizing a word. You also have to remember **where the stress falls**, which textbooks usually don't mark and which can change the meaning, and **what gender a noun is**, which decides every ending around it. Most flashcard apps treat a card as two plain strings, so both of those get lost.

**Тетрадь** (*tetrad'*, "exercise book") keeps them. Every card is a page of squared school-notebook paper with a red margin line, the kind of exercise book Russian students actually write in. The stressed vowel is printed in red pencil, and nouns carry a colored gender mark.

### Design Process

The whole look comes from one object: the squared *тетрадь* exercise book. The card is a sheet with a 24px blue grid and a red margin line, and the only other color on the page is the red used for stress, as if marked in pencil by a teacher. One typeface (Golos Text, designed for Cyrillic) and a single narrow column keep the focus on the word itself.

I kept the controls quiet on purpose: plain text tabs for filters, one dark button for the main action, and keyboard shortcuts for the review loop, so a study session is mostly reading and remembering, not clicking.

### How It’s Built

<div class="my-8 space-y-4">
  <div class="p-5 bg-white dark:bg-gray-800 rounded border-l-4 border-blue-500">
    <div class="font-sans font-bold text-sm mb-2 text-black dark:text-white uppercase tracking-wide">One File, No Build Step</div>
    <div class="text-sm text-gray-600 dark:text-gray-400 font-serif leading-relaxed">Everything lives in a single <code class="font-mono text-xs bg-gray-100 dark:bg-gray-700 px-1 rounded">index.html</code> with vanilla JavaScript and no dependencies. Stress is stored as the Unicode combining acute accent (U+0301) after the vowel, and rendered by splitting the word on it.</div>
  </div>
  <div class="p-5 bg-white dark:bg-gray-800 rounded border-l-4 border-purple-500">
    <div class="font-sans font-bold text-sm mb-2 text-black dark:text-white uppercase tracking-wide">Runs Anywhere</div>
    <div class="text-sm text-gray-600 dark:text-gray-400 font-serif leading-relaxed">Built as a Claude Artifact, it uses the Artifact runtime when it’s there: a shared database that syncs cards across devices, and image reading for photo import. Opened anywhere else, it falls back to the browser’s <code class="font-mono text-xs bg-gray-100 dark:bg-gray-700 px-1 rounded">localStorage</code> and hides the photo button, with no setup.</div>
  </div>
  <div class="p-5 bg-white dark:bg-gray-800 rounded border-l-4 border-orange-500">
    <div class="font-sans font-bold text-sm mb-2 text-black dark:text-white uppercase tracking-wide">Careful Photo Import</div>
    <div class="text-sm text-gray-600 dark:text-gray-400 font-serif leading-relaxed">The photo prompt treats text in images as material to transcribe, never as instructions. Duplicates already in the deck are skipped, and every extracted row can be edited or removed in a review step before anything is saved.</div>
  </div>
</div>
