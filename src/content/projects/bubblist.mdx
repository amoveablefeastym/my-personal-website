*Personal project · macOS desktop app · open source*

Most to-do apps want to be opened. They live in a window you have to find, behind a Dock icon you have to click, in a layout built for managing projects rather than getting through a day. I wanted the opposite: something that stays out of the way until the moment I need it, and then feels light enough that I actually use it.

**Bubblist** is a small glass bubble that floats above everything on the desktop, showing how many tasks are left today. Click it and a see-through panel slides out with the day's list. Tick something off and confetti bursts from the checkbox. Click away and it tucks itself back in.

### Design Process

The look went through several rounds before it settled. It started as frosted glass, then became an editorial, magazine-like page with a serif masthead, then a typewriter-style manuscript set in Courier. Each version taught me something about what a list you glance at fifty times a day can carry. The serif and typewriter versions had character but slowed reading down, and heavy styling competed with the tasks themselves.

The final design keeps what worked: a light, widely spaced monospace face, soft charcoal text instead of black, section names set as small spaced capitals, and a strike-through that turns finished tasks gray rather than red. The panel itself became as clear as possible, using Apple's own Liquid Glass material so the desktop shows through and the list feels like part of the screen rather than a window on top of it. Interaction details were tuned the same way, by using it: clicking text to cross things off, a drag that never jumps, and resize handles that appear only on hover.

### How It's Built

<div class="my-8 space-y-4">
  <div class="p-5 bg-white dark:bg-gray-800 rounded border-l-4 border-blue-500">
    <div class="font-sans font-bold text-sm mb-2 text-black dark:text-white uppercase tracking-wide">Two Windows, Two Processes</div>
    <div class="text-sm text-gray-600 dark:text-gray-400 font-serif leading-relaxed">An Electron app with a main process that owns the windows, files, global shortcut, and login item, and two sandboxed web pages (the bubble and the panel) that talk to it only through a small preload bridge. The pages never touch the disk directly.</div>
  </div>
  <div class="p-5 bg-white dark:bg-gray-800 rounded border-l-4 border-purple-500">
    <div class="font-sans font-bold text-sm mb-2 text-black dark:text-white uppercase tracking-wide">Native Liquid Glass</div>
    <div class="text-sm text-gray-600 dark:text-gray-400 font-serif leading-relaxed">On macOS 26 the panel and bubble sit on a real <code class="font-mono text-xs bg-gray-100 dark:bg-gray-700 px-1 rounded">NSGlassEffectView</code>, attached through a native add-on, with the page's own background left transparent. Older systems fall back to the standard vibrancy blur.</div>
  </div>
  <div class="p-5 bg-white dark:bg-gray-800 rounded border-l-4 border-teal-500">
    <div class="font-sans font-bold text-sm mb-2 text-black dark:text-white uppercase tracking-wide">State → Render</div>
    <div class="text-sm text-gray-600 dark:text-gray-400 font-serif leading-relaxed">No framework. All tasks live in one state object; every change updates it, saves it, and re-renders the list from scratch, so the screen can never drift out of sync with the data. Daily, weekday, and weekly repeats are stored once and track completion per day or per week.</div>
  </div>
  <div class="p-5 bg-white dark:bg-gray-800 rounded border-l-4 border-green-500">
    <div class="font-sans font-bold text-sm mb-2 text-black dark:text-white uppercase tracking-wide">Smooth Dragging</div>
    <div class="text-sm text-gray-600 dark:text-gray-400 font-serif leading-relaxed">Instead of rearranging the list under the cursor (which makes rows jump), the drag measures every row once when it starts, works out the drop point from that fixed snapshot, and slides rows aside with CSS transforms. Nothing changes in the list until the task is dropped.</div>
  </div>
  <div class="p-5 bg-white dark:bg-gray-800 rounded border-l-4 border-orange-500">
    <div class="font-sans font-bold text-sm mb-2 text-black dark:text-white uppercase tracking-wide">Private by Default</div>
    <div class="text-sm text-gray-600 dark:text-gray-400 font-serif leading-relaxed">Everything is stored locally as a plain JSON file. No accounts, no server, no network calls. The packaged app is built with a custom script that bundles, signs, and installs it, and releases are published on GitHub.</div>
  </div>
</div>
